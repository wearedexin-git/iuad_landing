# Font del progetto

Inserisci qui i file dei font **Tiempos** e **Sarabun**.

Formati supportati: `.woff2`, `.woff`, `.ttf`

Dopo aver aggiunto i file, indicami i nomi esatti (es. `TiemposHeadline-Bold.woff2`, `Sarabun-Light.woff2`) così configuro gli `@font-face` e aggiorno il sito per usare solo questi due font.
